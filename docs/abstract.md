# Abstract

В проекте исследуется локальная геометрия функции потерь сверточных нейросетей на CIFAR-10 через двумерные сечения loss landscape в пространстве параметров модели. Рассматривается поверхность `f(alpha, beta) = L(theta + alpha d1 + beta d2)` в случайной плоскости нормированных направлений с filter-wise normalization. Для аппроксимации поверхности сравниваются три квадратичные модели: полная least-squares квадратика с PD-проекцией, диагональная квадратика и Hessian-based модель по конечным разностям. Качество аппроксимаций оценивается по метрикам `RMSE`, `L_inf`, `RelRMSE`, а также по 1D-срезам `f(alpha, 0)` и `f(0, beta)`.

Реализация оформлена как воспроизводимый pipeline (`run_pipeline.py`) с единой точкой входа, сохранением артефактов, графиков и таблиц метрик. На доступных результатах для `model1` (малый радиус `r=0.1`) показано, что `q1` и `q2` обеспечивают существенно более точное приближение, чем `q3`, что согласуется с чувствительностью конечно-разностной оценки Гессиана к выбору шага `eps` и численному шуму. Работа демонстрирует практический workflow для анализа loss landscape и может использоваться как база для расширения экспериментов (мульти-seed плоскости, sweep по `eps`, сравнение архитектур).
