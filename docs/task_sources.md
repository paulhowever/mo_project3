# Реестр исходных материалов

Этот файл фиксирует, какие исходные материалы используются в проекте и зачем они нужны.

## Основные документы

1. `mo_lab3_pla.pdf`
   - Тип: основное задание по лабораторной работе.
   - Роль: первичный источник требований к цели, процессу и ожидаемым результатам.
   - Статус: в репозитории хранится оригинал.

2. `Проектное задание 3 (добровольное).docx.pdf`
   - Тип: дополнительное/расширенное проектное задание.
   - Роль: источник уточнений по добровольной части и возможному расширению базовой работы.
   - Статус: в репозитории хранится оригинал.

3. `NeurIPS-2018-visualizing-the-loss-landscape-of-neural-nets-Paper.pdf`
   - Тип: научная статья (референс).
   - Роль: теоретическая опора для раздела обзора литературы и обсуждения методологии.
   - Статус: в репозитории хранится оригинал.

## Правила использования источников

- Любые формулировки требований в `README.md` и отчете сверяются с `mo_lab3_pla.pdf`.
- Если появляется неоднозначность, в отчете явно указывается, из какого документа взята трактовка.
- При добавлении новых источников обновлять этот реестр обязательно.
