# A. Краткий аудит репозитория

## 1) Что делает проект

Проект реализует исследовательский pipeline анализа `loss landscape` на CIFAR-10: обучение модели, построение 2D-сечения в пространстве параметров, аппроксимации поверхности, расчёт метрик и визуализация.

## 2) Научная цель

Проверить, насколько хорошо локальная квадратичная модель описывает геометрию функции потерь в окрестности обученного решения, и сравнить разные варианты аппроксимации.

## 3) Используемые методы

- Filter-wise normalization случайных направлений.
- Full quadratic fit (`q1`) с PD-проекцией.
- Diagonal quadratic fit (`q2`).
- Hessian-based finite-difference quadratic (`q3`).
- Метрики: `RMSE`, `L_inf`, `RelRMSE`; плюс 1D-срезы.

## 4) Эксперименты

- Базовый: surface + `q1/q2/q3` для `model1`.
- Sweep по радиусам `RADIUS_LIST`.
- 1D-профили по осям `alpha` и `beta`.
- Smoke-режим на синтетических данных для быстрой проверки пайплайна.

## 5) Результаты

На зафиксированных данных для `model1` при `r=0.1` аппроксимации `q1/q2` заметно точнее `q3` по всем ключевым метрикам.

## 6) Сильные стороны

- Чёткое модульное разделение кода.
- Единая точка входа (`run_pipeline.py`).
- Наличие smoke-режима.
