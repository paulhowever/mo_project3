# Project 3: MO Labs

Репозиторий подготовлен как каркас для лабораторного проекта в смешанном формате:
- вычислительный код в `src/`;
- исследовательские эксперименты в `notebooks/`;
- документация и отчетные материалы в `docs/`.

## Цель репозитория

Сделать выполнение лабораторной воспроизводимым и прозрачным:
- хранить требования и источники в одном месте;
- разделять код, эксперименты и текст отчета;
- обеспечить единый формат подготовки результатов к сдаче.

## Базовый workflow

1. Изучить постановку и источники:
   - `mo_lab3_pla.pdf`
   - `docs/task_sources.md`
2. Запланировать этапы работы через `docs/roadmap.md`.
3. Выполнять эксперименты в `notebooks/` и переносить стабильные части в `src/`.
4. Оформлять результаты по шаблону `docs/report_template.md`.

## Воспроизводимость

- Не хранить временные файлы и артефакты окружения в git (см. `.gitignore`).
- Поддерживать однозначные имена ноутбуков и документов.
- Любые отклонения от исходной постановки фиксировать в отчете отдельным пунктом.

## Связанные документы

- Гайд по вкладу и оформлению: `CONTRIBUTING.md`
- Шаблон отчета: `docs/report_template.md`
- План этапов: `docs/roadmap.md`
- Реестр источников: `docs/task_sources.md`
